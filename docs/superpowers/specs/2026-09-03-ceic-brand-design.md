# CEIC 标题标识统一设计

## 目标

登录页和登录后工作区的标题统一使用项目内的 CEIC 标识，并保持相同的标题文字样式。

## 实施范围

- `PlatformBrand` 统一引用 `/assets/logo-red.png`，作为所有标题的标识。
- 登录页继续直接渲染 `PlatformBrand`。
- 工作区头部改为渲染同一组件，不再以包含旧图标和转曲旧标题的 `主表头.svg` 作为标题内容。
- 工作区保留原有深色头部、尺寸及轮廓装饰；标题文字沿用 `PlatformBrand` 的字体、字重、颜色和阴影。

## 非目标

- 不改变登录表单、导航、接口或认证逻辑。
- 不修改 CEIC 标识文件本身。

## 验收

- 登录页标题和各登录后页面标题均显示 CEIC 标识。
- 两处标题文字的字体样式一致。
- 前端类型检查和生产构建通过。
